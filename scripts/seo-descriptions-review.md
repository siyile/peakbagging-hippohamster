# Post descriptions — REVIEW (v3: two fields)

HOW THIS WORKS
- DISPLAY = posts.description. Short text shown on the site (post subtitle and
  card previews). Keep it short.
- META = posts.meta_description. Longer sentence used only for the Google
  <meta description>. Rendered as META + " " + SUFFIX (search-only tail).

SUFFIX (appended in code): Route beta and photos.

Edit any DISPLAY or META line. Leave slug alone. update-descriptions.mjs writes
DISPLAY -> description and META -> meta_description.
