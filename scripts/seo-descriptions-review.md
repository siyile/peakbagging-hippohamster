# Post descriptions — REVIEW (v2: dash-free, split on-page vs meta)

HOW THIS WORKS
- ONPAGE = the clean sentence stored in `posts.description`. This is what shows
  on the site (post subtitle + card previews). No dashes, no SEO boilerplate.
- The Google `<meta description>` is generated in code as:  ONPAGE + " " + SUFFIX
  so the search-only tail never appears while browsing.

SUFFIX (proposed): Detailed route beta and trip photos.

Edit any ONPAGE line you want to change. Leave slug/OLD alone. When approved I'll
write ONPAGE into the DB and add the suffix-composition in generateMetadata.
